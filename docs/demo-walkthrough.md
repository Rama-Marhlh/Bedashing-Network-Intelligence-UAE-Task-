# 5–10 minute demo walkthrough

1. Frame the right-sizing problem and human decision-maker.
2. Open Network Overview; show dynamic decision/whitespace KPIs, legend, and no-key map.
3. Select a branch and introduce the shared seven-tab details.
4. Switch 5/10/15-minute catchments; explain road-network modelling.
5. Show self-overlap versus unique coverage.
6. Enable DIRECT/ADJACENT competitors; open one and inspect validated branch relationships.
7. Open Performance & Health and explain why “performance” is a proxy.
8. Compare 2–4 branches using grouped components, sentiment, competition, coverage, and overlap.
9. Show exact PROTECT/HOLD/SHRINK thresholds, drivers, limitations, and guardrail.
10. Enable whitespace, filter GROW/WATCH/SKIP, and click a cell to inspect evidence/scopes.
11. Open a Reviewed Top 10 area and show coordinates, sanity flags, and next checks.
12. Search Arabic or English reviews; show full-export scope, original text, and pagination.
13. Filter sourced services/prices; state that branch availability is unknown.
14. Explain a financial scenario using its sourced/derived/assumed inputs and worked calculation.
15. Ask a fresh AI prompt to compare branches or display a catchment; verify the main UI changes.
16. Close on the provenance and limitation notes embedded in the relevant branch, growth, review, competitor, and financial views.
